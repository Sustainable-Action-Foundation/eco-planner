# Workspace context

Compact notes on how things are and why, for a developer or coding agent new to the repo. Read the relevant file before working in an area; update it when a decision changes. Each file describes the code on `dev` in the present tense: no history, no status.

Other references these files link to rather than repeat: [`README.md`](../../README.md) (setup, env vars, components, CSS), [`caching.md`](../../caching.md) (cache tags and invalidation rules), [`locales.md`](../../locales.md) (i18n namespaces and formatters), [`tests/MANIFEST.md`](../../tests/MANIFEST.md) (test harness and plan), `AGENTS.md` (generated by `next dev`: read the bundled Next docs, this Next differs from older versions).
